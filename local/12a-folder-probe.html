12-A 실제 폴더 검증

완성된 업무관리 프로그램이 아닙니다. Windows Edge·Chrome에서 이 HTML을 더블클릭해 파일 저장 지원을 확인하는 도구입니다. 인터넷이나 로그인이 필요하지 않습니다.

비어 있는 테스트 폴더를 선택하세요. 그 안에 이름이 고유한 wm-local-probe-… 폴더와 data, attachments, holidays, backups, journal 하위 폴더를 만듭니다. 기존 파일은 삭제하지 않습니다.

1번 완료 후 탐색기에서 실제 파일을 확인하고 브라우저를 완전히 종료하세요. 같은 위치의 HTML을 다시 열어 2번을 누릅니다. 테스트 폴더·파일을 삭제하거나 이동한 경우 실패가 정상입니다.
