업무관리 로컬판 12-B — Windows Edge 시험 안내

이 ZIP은 12-B Windows 검증용입니다. 실제 업무에 사용하지 마세요.
첨부 원본 관리와 공식 공휴일 자동 갱신은 12-C 예정입니다.
전체 업무 UI 및 Windows 파일시스템 동작은 아직 검증되지 않았습니다.

1. ZIP을 Windows PC의 원하는 위치에 압축 해제합니다.
2. 업무관리.html을 더블클릭하여 Microsoft Edge에서 직접 엽니다.
   주소가 file:/// 로 시작하는지 확인합니다. 서버나 별도 프로그램 설치는 필요하지 않습니다.
3. 반드시 기존 운영 업무 폴더가 아닌 새 빈 테스트 폴더를 만듭니다.
   화면의 '업무관리 폴더 선택'으로 그 폴더를 선택하고 쓰기 권한을 허용합니다.
4. HOME 화면이 나타나는지 확인합니다. 오류가 보이면 문구를 기록하고 시험을 중단합니다.
5. 실제 자료가 아닌 '합성 시험 업무' 한 건을 만들고 저장합니다.
   하단 저장 상태가 확인됐는지 확인합니다. 저장 실패 안내가 뜨면 성공으로 간주하지 마세요.
6. Windows 탐색기에서 선택한 테스트 폴더의 data 및 journal 하위 폴더에
   HEAD.json, snapshot-*.json, *.intent.json, *.receipt.json 등이 있는지 확인합니다.
7. HTML 탭을 닫았다 다시 열고 '이전 폴더 재연결'을 선택합니다.
   권한을 재요청하면 허용하고 합성 시험 업무가 그대로 있는지 확인합니다.
   재연결 버튼이 비활성이라면 같은 테스트 폴더를 다시 선택합니다.
8. 첫 창을 열어둔 채 별도 Edge 창에서 같은 HTML과 같은 테스트 폴더를 엽니다.
   두 번째 창에서 배타 잠금/충돌 안내가 나오는지 확인합니다.
   두 창에서 동시에 업무를 저장하지 마세요.

시험 결과에 Edge 버전, HOME 표시 여부, 저장/재연결 여부, 두 번째 창의 안내 문구를 기록하세요.
비밀번호, 실제 업무 내용, 토큰, 운영 폴더나 첨부 원본을 시험에 사용하지 마세요.
시험 중 문제가 생기면 테스트 폴더 원본을 그대로 보존하고 임의로 journal을 삭제하지 마세요.
