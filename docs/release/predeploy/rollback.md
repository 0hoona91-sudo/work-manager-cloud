# 배포 실패 시 중단·복구

완료 이력 손실, 타 계정 데이터 노출, 생성키 중복, 프로젝트 무단 덮어쓰기, 원본 누락, 대규모 저장 거부가 확인되면 편집을 중지하고 배포 SHA·Rules 원본/새 버전·journal·백업 manifest를 보존한다. 미확정 명령을 자동 재전송하거나 브라우저 저장소를 지우지 않는다.

Pages 코드 오류만 있고 Rules를 아직 바꾸지 않았다면, 승인된 운영 담당자가 직전 검증 SHA의 정적 파일로 되돌리는 커밋을 `main`에 적용한다. 이미 강화 Rules를 적용했다면 구형 코드만 되돌리면 체크리스트·반복 저장이 거부될 수 있으므로 기존 Rules의 보관본과 보안 영향을 별도로 비교하고 승인 후 전환한다. 포괄적 허용 규칙으로 무조건 되돌리지 않는다.

Firestore 데이터와 Drive 원본은 코드 롤백으로 복구되지 않는다. JSON에는 첨부 원본이 없으므로 ZIP의 원본·누락·해시 목록을 함께 확인한다. 복원은 미리보기·동일 ID 충돌·완료 이력 보호·명시적 승인을 거친다. 이미 성공한 일부 서버 쓰기는 자동 취소할 수 없으며, 보관한 journal/첨부 복구 기록으로 수동 대조한다. Git 이력은 새 revert 커밋으로 보존하고 force push하지 않는다.
