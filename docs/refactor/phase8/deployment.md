# 8단계 운영 전 점검과 롤백

8단계는 개발 브랜치·합성 자료에만 적용했다. main, Pages, 운영 Firebase·Rules·Drive를 변경하지 않았다. 운영 반영은 기존 단계의 별도 승인·검증을 따른다.

운영 전 실계정에서 홈·달력·검색 IME, 네 화면 폭과 회전, 업무 편집 중 실시간 갱신, 저장 충돌·오프라인, 프로젝트 단계 편집과 완료 잠금, 첨부 열기, 설정·테마·휴지통 복원 절차를 확인해야 한다. 테스트 브라우저의 Emulator 성공은 실계정 인증과 운영 자료를 대신하지 않는다.

남은 기술부채: index.html의 다층 renderer wrapper 전체를 이번에 제거하지 않았다. 제거 전 실제 호출 순서와 동적 DOM 의존을 특성화해야 한다. project-ui.js의 라이브러리 편집 MutationObserver는 동적 입력/버튼을 보정하는 기존 역할이 있어 유지했다. BUG-02 CSS 구문 오류와 전체 스타일 개편은 9단계다. 브라우저 저장소·원격 서버를 아우르는 완전한 원자성은 기존 저장 계층의 한계다.

롤백은 phase8 중간 커밋을 역순으로 `git revert`하고 해당 UI 집중 검사와 전체 회귀를 재검증한다. 기존 커밋·ID·완료 이력·journal을 초기화하거나 force push하지 않는다. 문서만 추가된 최종 커밋은 성공한 코드 CI SHA의 검증 결과를 재사용한다.
