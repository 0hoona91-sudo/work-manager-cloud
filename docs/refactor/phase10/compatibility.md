# 구형 클라이언트·데이터 호환성

합성 schema11로 `INTEG-LEGACY-01`을 확인했다. 예전 업무·체크 ID, 첨부 ID/Drive ID, generatedKey, completionHistory, Google Tasks 유래 메타데이터와 설정은 cloud codec 왕복 및 JSON 백업 미리보기에서 보존된다. schema 표기가 없는 옛 JSON도 필수 구조 검증 후 경고를 반환한다. 자동 마이그레이션이나 ID 재발급은 없다.

기존 `PREFLIGHT-02/04`, `PROVISION-EMU-08`, `JOURNAL-SDK`는 비표준 잠금·tombstone·부모 없는 체크리스트·미확정 journal을 진단하고, 구형 클라이언트의 부모 revision 없는 체크리스트 쓰기가 **새 테스트 규칙에서 거부**됨을 보여준다. 이 거부는 데이터 유실 없는 자동 업그레이드가 아니다. 기존 브라우저 캐시·오프라인 대기 명령을 갖고 있는 실제 사용자에게는 저장 실패가 날 수 있다. 운영 규칙은 확인하지 않았으므로 실제 적용 여부를 단정하지 않는다.

운영 전에는 사용 중인 캐시 버전과 오프라인 대기 작업을 확인하고, 새 클라이언트 배포·재접속 안내·미확정 journal 검토 뒤 보안 규칙 전환을 따로 승인해야 한다. 이전 HTML과 신규 JS/asset이 섞이는 경우도 테스트하지 않았다. 캐시·journal을 강제 삭제하지 않으며, 실제 오래된 프로젝트/첨부 레코드의 모든 변형은 미검증이다.
