# 확인된 한계와 배포 영향

- 1만 업무 Gantt의 기존 `Invalid string length`는 이번 브랜치에서 표시 페이지(500건) 선택으로 재현되지 않는다. 1천 건 이하는 기존 전체 표시를 유지한다. 대량 데이터 전체에 대한 사용자 시험은 아직 없다.
- 같은 1만 업무 fixture에서 일반 업무 목록 표시가 약 25초다. 검색·달력·프로젝트 표시와 메모리도 업무 분포·기기 성능에 따라 달라질 수 있다. 운영 데이터 규모를 조회하지 않았으므로 실제 영향은 미확정이다. 저사양 모바일의 대량 데이터 시나리오는 배포 전 별도 확인이 필요하다.
- 독립 일반 업무의 동시 편집과 반복 생성키는 실제 SDK/Emulator로 검증됐다. 프로젝트 단계 전체 저장, 구형 클라이언트의 오프라인 쓰기, 실제 서로 다른 물리 기기의 장기 오프라인 경합은 동일한 보장을 얻지 못했다. `PROVISION-EMU-08`의 구형 부모 revision 없는 쓰기 거부는 전환 위험이다.
- Firebase/Drive 사이의 전역 트랜잭션은 없고 브라우저 저장소 삭제 시 journal 복구가 불가능하다. JSON 구조 백업은 원본 파일을 포함하지 않으며 ZIP은 단일 50MB·총 200MB·1000파일 한도가 있다.
- 실제 Google OAuth·Drive API·운영 Security Rules·운영 자료·권한 도메인은 조회 또는 검증하지 않았다. 실제 운영 계정·테스트 폴더와 사용자 승인이 필요하다.
- Chromium의 네 대표 너비, 키보드 빠른 업무, IME, 테마 자원과 취소 경로를 검사했다. 전체 화면의 스크린리더 접근성·명도·모든 모달 focus 복귀는 수동 점검이 필요하다.
