# 승인·외부 환경 검증 대기 목록

| 대상 | 필요한 범위 | 현재 판정 |
|---|---|---|
| 실제 Google OAuth | 승인된 테스트 계정·도메인에서 로그인, 재인증 취소, 로그아웃·계정 전환 | 미검증; 모의 AUTH/DRIVE 계약만 PASS |
| 실제 Google Drive | 격리 테스트 폴더의 파일 업로드·열기·다운로드·권한 만료·원본 포함 ZIP | 미검증; 운영 파일에는 접근하지 않음 |
| 운영 Firebase/Firestore 규칙 | 현재 규칙 diff, 승인 UID, 생성키 잠금, 부모 revision, 구형 요청, 규칙 롤백본 | 미검증; demo Emulator 규칙만 PASS |
| 운영 데이터 규모·백업 | 업무 수/기간, 미확정 journal·오프라인 큐, JSON+원본 보존 계획 | 미검증; 운영 데이터 조회 금지 유지 |
| 구형 브라우저 캐시 | 새 HTML/JS/asset 혼합 로딩 및 오래된 클라이언트 저장 거부 안내 | 미검증; 실제 사용자 세션 조사 필요 |
| Pages 배포 | `/work-manager-cloud/` CDN 자원, 캐시·PWA, 모바일·테마, 배포 후 점검 | 개발 서버 가상 하위경로만 PASS; 운영 배포 승인 대기 |

이 목록의 실제 서비스 검사는 별도 사용자 승인과 안전한 테스트 환경이 있어야 진행한다. 승인 전에는 main 병합·운영 Pages·Rules 변경을 하지 않는다.
